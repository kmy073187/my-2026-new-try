## 对Git概念的理解
git仓库是一棵大树，分支就像是大树上的每一个枝干，我所提交的commit就是main这个主枝干的节点；合并就是把在其他枝干上长出的硕果接到主枝干上，让它们都能在同一棵大树下生长

## 常用命令行的用途
cd：切换所在的文件夹
ls：了解当前文件夹所有的文件
mkdir：新建文件夹
git add：把改动的文件放入暂存区，准备提交
git commit：把暂存区的内容存档为一个版本节点
git push:把本地的存档上传到GitHub
git pull：把GitHub上最新的内容拉取到本地


## 为什么要选择NIT协议
