## 对Git概念的理解
git仓库是一棵大树，分支就像是大树上的每一个枝干，我所提交的commit就是main这个主枝干的节点；合并就是把在其他枝干上长出的硕果接到主枝干上，让它们都能在同一棵大树下生长

## 常用命令行的用途
cd：切换所在的文件夹
ls：了解当前文件夹所有的文件
mkdir：新建文件夹
git add：把改动的文件放入暂存区，准备提交
git commit：把暂存区的内容存档为一个版本节点
git push:把本地的存档上传到GitHub
git pull：把GitHub上最新的内容拉取到本地

## 防纯粘贴承诺
在制作ai自动模式时，看起来蛇是一直在动的，但原理是蛇每次移动的时候都在开头插入新的蛇头，在step函数中，const head代码便是算出蛇头应该在哪个格子，移动时再把末尾的方块删掉，如果蛇吃到食物，那么末尾的方块就不删掉，snake unshift（head）就是在开头插入新蛇头，一加一删，就是蛇能前进的关键；
AI每一步把上下左右四个方向按曼哈顿距离排序，曼哈顿距离就是横着差几格加竖着差几格，数字越小说明离食物越近，这一步由dirs.sort代码来完成，然后从近到远逐个检查格子是否会出界或撞到自己，从而选安全的走

## 进阶挑战
## 论文思路理解
这篇论文介绍了一个叫Croc的教学项目，这个平台让学生能完整体验芯片设计的流程，而且里面大多是免费的EDA工具，可专门给学生上课用，是业界对芯片设计人才的需求。在首次课程实践中，65名同学用Croc完成了33个项目，其中30个生成了可制造的版图，这也说明了Croc是一个降低芯片设计学习门槛的教学平台。Croc依托开源RISC-V处理器内核，搭配全套开源EDA工具，把芯片设计的前、后端流程整合在了一起。
## 前端
前端主要是验证逻辑对不对，运用Verilator把芯片代码变成能跑的程序。工程师把电路代码写出来之后不一定没有bug，所以前端就可以验证功能是否正确。把hell world这样的测试程序放在模型里面跑，如果它能正确体现出来，就说明逻辑的设计是对的。
## 后端
因为芯片最终得制造出来，所以需要后端把验证过的Verilog代码转换出来，变成一个个真实的电路门，然后把这些门摆放到芯片的具体位置，再连好线，最后就生成了一个可运行的文件。
